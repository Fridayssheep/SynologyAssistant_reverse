Synology Assistant

Synology Assistant ist ein benutzerfreundliches Tool zur Verwaltung von Speichersystemen im lokalen Netzwerk (LAN), insbesondere wenn Sie mehrere Geräte im LAN betreiben.

Um Synology Assistant auf Ihrem Computer herunterzuladen und zu installieren, gehen Sie zum Download-Zentrum und wählen Sie Ihr Modell aus. Gehen Sie anschließend zum Tab Desktop-Dienstprogramme, um Synology Assistant zu finden.

Grundlegende Steuerung

Synology Assistant läuft im Hintergrund, wenn das Programm in die Taskleiste minimiert wird. Klicken Sie mit der rechten Maustaste auf das Symbol, um folgende Optionen aufzurufen:

  • Drucker anhängen/freigeben: Bis zu 2 Drucker
  • Assistant öffnen/schließen

Verwaltung

So suchen Sie nach Speichersystemen im LAN:

Klicken Sie auf Suchen, um die Liste der Speichersysteme in Ihrem LAN zu aktualisieren.

So verbinden Sie sich mit einem Server:

Sie können sich auf eine der folgenden Arten mit Ihrem Server verbinden:

  • Wählen Sie einen Server aus und klicken Sie auf Verbinden.
  • Doppelklicken Sie auf einen Server.

So binden Sie ein Laufwerk ein:

Klicken Sie auf Laufwerk verbinden, um einen freigegebenen Ordner als Netzlaufwerk für den lokalen Zugriff einzubinden.

So richten Sie WOL ein:

Sie können Wake on LAN (WOL) einrichten, um Ihre Synology-Speichersysteme aus der Ferne zu starten, wenn Sie diese Funktion unter Systemsteuerung > Hardware & Energie > Allgemein aktiviert haben. Wählen Sie einen Server aus der Liste und klicken Sie auf WOL einrichten. Weitere Informationen finden Sie im Abschnitt WOL.

Hinweis:

Die Optionen für Laufwerkszuordnung und WOL sind nicht verfügbar, wenn Ihr Synology-Gerät diese Funktionen nicht unterstützt.

WOL

So richten Sie WOL ein:

  1. Gehen Sie zu Systemsteuerung > Hardware & Energie > Allgemein und aktivieren Sie WOL.
  2. Öffnen Sie in Synology Assistant den Tab Verwaltung. Wählen Sie einen Synology NAS aus und klicken Sie auf WOL einrichten, um die für WOL verfügbare MAC-Adresse anzuzeigen.
  3. Nach der Einrichtung ändert sich der WOL-Status des Servers im Tab Verwaltung auf "WOL".

Hinweis:

  1. Die WOL-Funktion wird nur von einigen Synology NAS-Modellen unterstützt. Weitere Informationen finden Sie im Produktdatenblatt Ihres Servers.
  2. Sie können auch mit der rechten Maustaste auf einen Server klicken und WOL > Einrichten auswählen.

So wecken Sie einen Server auf:

  1. Klicken Sie mit der rechten Maustaste auf einen Server und wählen Sie WOL > Aufwecken.
  2. Der WOL-Status des Servers ändert sich auf "Fortschritt X%", was den Aufweckfortschritt anzeigt.
  3. Wenn WOL abgeschlossen ist, ändert sich der WOL-Status auf "WOL". Weitere Informationen zu WOL-Status finden Sie in der folgenden Tabelle.
    4. WOL-Status Statusanzeige
    WOL
    1. WOL ist eingerichtet.
    2. Server ist eingeschaltet.
    --
    1. WOL ist nicht eingerichtet.
    2. Server unterstützt die WOL-Funktion nicht.
    Progress X% Server wird eingeschaltet. Aufweckfortschritt ist X%.
    Off Server ist ausgeschaltet.
    N/A WOL ist eingerichtet, aber der aktuelle Status ist unbekannt.

So deaktivieren Sie WOL für einen Server:

  1. Klicken Sie mit der rechten Maustaste auf einen Server und wählen Sie WOL > Entfernen.
  2. Der WOL-Status des Servers ändert sich auf "--".

Druckergerät

Im Synology Assistant können Sie Drucker, die an Ihren Synology NAS angeschlossen sind, zentral auf dem Tab Druckergerät verwalten. Sowohl einfache als auch Multifunktionsdrucker werden unterstützt. Um einen an den Synology NAS angeschlossenen Drucker im LAN über Synology Assistant freizugeben, befolgen Sie diese Anweisungen.

Beachten Sie, dass Druckergeräte nur auf einigen Synology NAS-Modellen mit DSM unterstützt werden. Weitere Informationen finden Sie im Produktdatenblatt Ihres Servers.

So fügen Sie einen Drucker hinzu:

  1. Schließen Sie den Drucker an Ihren Synology NAS an.
  2. Richten Sie den Druckermodus unter Systemsteuerung > Externe Geräte ein. Hier wird eine Liste der angeschlossenen Drucker angezeigt.
  3. Wählen Sie den Drucker aus, klicken Sie auf USB-Druckermanager und wählen Sie Drucker einrichten, um den Betriebsmodus für Ihren Drucker auszuwählen. Wählen Sie den Modus Netzwerkdrucker, wenn Sie nur die Druckfunktion nutzen. Wählen Sie Netzwerk-MFP*, wenn Sie drucken, scannen oder faxen möchten.
  4. Gehen Sie im Synology Assistant zum Tab Druckergerät. Klicken Sie auf Hinzufügen und folgen Sie dem Einrichtungsassistenten, um den Drucker zu Ihrem Computer hinzuzufügen. Wenn Sie den Drucker zum ersten Mal hinzufügen, halten Sie den Druckertreiber für die Installation bereit.

So hängen Sie einen Drucker an/freigeben:

Beim Drucken und Faxen können Sie die Vorgänge ausführen, ohne den Drucker manuell im Synology Assistant anzuhängen. Wenn Sie jedoch die Scannerfunktion nutzen oder Faxe auf einem Multifunktionsdrucker empfangen möchten, müssen Sie den Drucker anhängen, um zu verhindern, dass Druckaufträge von anderen Benutzern unterbrochen werden.

Wenn ein Drucker manuell im Synology Assistant angehängt ist, können andere Benutzer, die denselben Drucker im LAN gemeinsam nutzen, nicht auf das Gerät zugreifen. Stellen Sie sicher, dass Sie den Drucker freigeben, wenn Sie Ihren Druckauftrag abgeschlossen haben.

Sie können diese Anweisungen befolgen, um den Drucker anzuhängen oder freizugeben.

  1. Gehen Sie im Synology Assistant zum Tab Druckergerät.
  2. Wählen Sie den Drucker aus, den Sie anhängen möchten, und klicken Sie auf Anhängen. Synology Assistant beginnt mit der Verbindung zum Drucker. Die Statusspalte zeigt den Betriebszustand an.
  3. Wenn ein Drucker angehängt ist, wird die Schaltfläche Anhängen zu Freigeben. Sie können darauf klicken, um den angehängten Drucker freizugeben.

Hinweis:

  • Wenn in der Statusspalte der Status des Druckers Verfügbar ist, können Sie den Drucker exklusiv anhängen.
  • Wenn der Status Angehängt ist, ist der Drucker bereits an Ihren Computer angehängt.
  • Wenn der Drucker derzeit nicht verfügbar ist, werden Sie durch Klicken auf Anhängen auf die Warteliste für die Verbindung gesetzt.

So entfernen Sie einen Drucker:

  1. Wählen Sie den Drucker aus, den Sie aus der Liste entfernen möchten.
  2. Klicken Sie auf Entfernen, um den Drucker aus der Liste zu löschen.

So bearbeiten Sie Druckerinformationen:

Wenn Synology Assistant die IP-Adresse Ihres Druckers nicht automatisch erkennt, können Sie die IP hier manuell einrichten.

  1. Wählen Sie den Drucker aus, den Sie bearbeiten möchten.
  2. Klicken Sie auf Bearbeiten und geben Sie die korrekte IP-Adresse Ihres Druckers ein.

Hinweis:

  • Netzwerk-MFP ist nur für Windows-Benutzer verfügbar.
  • Bevor Sie einen Drucker einrichten, beachten Sie die Liste der kompatiblen Drucker.
  • USB-Hubs werden beim Anschluss eines Druckers zur Freigabe nicht unterstützt.
  • Die Speicherkartenfunktion des angeschlossenen Druckers wird nicht unterstützt.

Einstellungen

Sie können auf das Zahnradsymbol mit der Bezeichnung Einstellungen oben rechts klicken, um die folgenden Einstellungen zu konfigurieren.

  • Standardfunktionstab: Wählen Sie die Funktionstabs aus, die in Synology Assistant angezeigt werden sollen.
  • Sprache: Wählen Sie eine Standardsprache für die Benutzeroberfläche von Synology Assistant. Sie müssen Synology Assistant neu starten, damit die neue Einstellung wirksam wird.
  • Speichertest: Wenn Sie das Kontrollkästchen aktivieren, erscheint die Schaltfläche Speichertest beim nächsten Start von Synology Assistant im Tab Verwaltung. Sie können einen Server auswählen und auf die Schaltfläche klicken, um einen Speichertest durchzuführen. Der Server wird neu gestartet und der Test beginnt. Der Testfortschritt wird in der Spalte Status der Serverliste angezeigt.

Hinweis:

  • Je nach Größe des physischen Speichers Ihres Servers kann der Speichertest einige Zeit in Anspruch nehmen. Bei Modellen mit zwei Controllern testen Sie jeweils nur einen Controller, damit das System während des Tests weiterhin Dienste bereitstellen kann.
  • Fehler bei der Verbindung zu Ihrem Server über Synology Assistant können Sie mit diesem Artikel beheben.

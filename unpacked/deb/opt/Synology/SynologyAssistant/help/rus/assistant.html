Synology Assistant

Synology Assistant — это простой в использовании инструмент для управления системами хранения данных в локальной сети (LAN), особенно если у вас несколько устройств, работающих в одной сети.

Чтобы скачать и установить Synology Assistant на свой компьютер, перейдите в Центр загрузок и выберите свою модель. Затем откройте вкладку Утилиты для настольных ПК, чтобы найти Synology Assistant.

Основное управление

Synology Assistant работает в фоновом режиме, когда свернут в системный трей. Щелкните правой кнопкой мыши по значку для доступа к следующим опциям:

  • Подключить/отключить принтеры: до 2 принтеров
  • Открыть/закрыть Assistant

Управление

Поиск систем хранения в локальной сети:

Нажмите Поиск, чтобы обновить список систем хранения в вашей локальной сети.

Подключение к серверу:

Вы можете подключиться к своему серверу одним из следующих способов:

  • Выберите сервер и нажмите Подключить.
  • Дважды щелкните по серверу.

Подключение сетевого диска:

Нажмите Подключить диск, чтобы подключить общую папку как сетевой диск для локального доступа.

Настройка WOL:

Вы можете настроить Wake on LAN (WOL) для удаленного включения ваших систем хранения Synology, если эта функция включена в Панель управления > Оборудование и питание > Общие. Выберите сервер из списка и нажмите Настроить WOL. Для получения дополнительной информации обратитесь к разделу WOL.

Примечание:

Опции подключения сетевого диска и WOL недоступны, если ваше устройство Synology не поддерживает эти функции.

Статус

В этой таблице перечислены статусы устройств в Synology Assistant и объясняется, что означает каждый статус.

Статус Описание статуса
Booting Система загружается.
Check progress Система устанавливается или настраивается. Нажмите, чтобы проверить ход выполнения.
Checking quota Система проверяет квоту диска. Это может быть результатом некорректного завершения работы.
Checking file system (X minutes remaining) Система проверяет файловую систему. Процесс завершится через указанное количество минут. Обычно это происходит, когда система обнаруживает ошибки файловой системы и предлагает выполнить её проверку.
Configuration error Произошла ошибка при настройке. Дважды щелкните по серверу, чтобы повторно применить настройки.
Configuration lost Обычно это происходит после Сброса режима 2, который выполняется путем нажатия и удержания кнопки RESET на устройстве. Вы можете дважды щелкнуть по серверу и переустановить операционную систему (ОС), чтобы начать заново без потери данных в томе. Если вы не нажимали кнопку RESET, проверьте другие возможные причины этого сообщения об ошибке.
Connection failed Ошибка сетевой конфигурации. Дважды щелкните по серверу или нажмите Настроить, чтобы изменить сетевые параметры.
Getting connection status Система проверяет состояние подключения.
Migratable Конфигурации системы на дисках могут быть перенесены на это устройство. Обычно это означает, что версия ОС, записанная на материнской плате, новее, чем версия ОС на дисках. Это часто происходит после обслуживания по RMA. Дважды щелкните по серверу для завершения процесса миграции.
N/A WOL настроен, но текущий статус неизвестен. Подробнее см. раздел WOL.
Not configured Начальная настройка ОС (например, пароль admin) после установки не завершена. Дважды щелкните по серверу для завершения настройки.
Not installed Возможные причины: на сервере не обнаружены диски; ОС не установлена; ОС не обнаружена на дисках; или вы нажали Удалить все данные в Панель управления > Обновление и восстановление > Сброс системы.
Решение: Убедитесь, что диски исправны, правильно установлены и определяются сервером. Затем дважды щелкните по серверу, чтобы начать установку ОС. Если ОС уже была установлена на дисках и вы использовали их ранее, это сообщение означает, что сервер не может распознать данные ОС на дисках. В этом случае отмените установку, выключите сервер, узнайте, почему диски не распознаются и проведите диагностику на компьютере для проверки состояния дисков.
Offline Система отключена от сети.
Performing Memory Test (X%) Выполнение теста памяти: X%. Если вам предложено провести тест памяти, выполните его не менее 3 раз. Результаты теста будут сохранены в системном журнале. Пожалуйста, создайте файл журнала debug.dat и приложите его к обращению в службу поддержки Synology для анализа.
Ready Система установлена и готова к использованию. Дважды щелкните по серверу или нажмите Подключить для доступа к серверу.
Recoverable Система подлежит восстановлению. Обычно это означает, что версия ОС на материнской плате старее, чем версия ОС на дисках. Это часто происходит после обслуживания по RMA. Дважды щелкните по серверу для завершения процесса восстановления.
Starting services Система запускает службы. Запуск всех служб может занять до 10 минут.
Upgrading Устройство обновляет ОС. Пожалуйста, дождитесь завершения процесса обновления.

WOL

Настройка WOL:

  1. Перейдите в Панель управления > Оборудование и питание > Общие и включите WOL.
  2. В Synology Assistant откройте вкладку Управление. Выберите Synology NAS и нажмите Настроить WOL, чтобы просмотреть доступный MAC-адрес для WOL.
  3. После настройки статус WOL на вкладке Управление изменится на «WOL».

Примечание:

  1. Функция WOL поддерживается только на некоторых моделях Synology NAS. Подробнее см. руководство по продукту вашего сервера.
  2. Вы также можете щелкнуть правой кнопкой мыши по серверу и выбрать WOL > Настроить.

Включение сервера с помощью WOL:

  1. Щелкните правой кнопкой мыши по серверу и выберите WOL > Включить.
  2. Статус WOL сервера изменится на «Progress X%», что означает ход включения.
  3. После завершения WOL статус изменится на «WOL». Подробнее о статусах WOL см. в таблице ниже.
    4. Статус WOL Описание статуса
    WOL
    1. WOL настроен.
    2. Сервер включен.
    --
    1. WOL не настроен.
    2. Сервер не поддерживает функцию WOL.
    Progress X% Сервер включается. Ход включения: X%.
    Off Сервер выключен.
    N/A WOL настроен, но текущий статус неизвестен.

Отключение WOL для сервера:

  1. Щелкните правой кнопкой мыши по серверу и выберите WOL > Удалить.
  2. Статус WOL сервера изменится на «--».

Устройство принтера

В Synology Assistant вы можете централизованно управлять принтерами, подключенными к вашему Synology NAS, на вкладке Устройство принтера. Поддерживаются как обычные, так и многофункциональные принтеры. Чтобы предоставить общий доступ к принтеру, подключенному к Synology NAS в локальной сети через Synology Assistant, выполните следующие действия.

Обратите внимание, что поддержка устройств принтера реализована только на некоторых моделях Synology NAS с установленной DSM. Подробнее см. руководство по продукту вашего сервера.

Добавление принтера:

  1. Подключите принтер к вашему Synology NAS.
  2. Настройте режим работы принтера в Панель управления > Внешние устройства. Здесь отображается список подключенных принтеров.
  3. Выберите принтер, нажмите Диспетчер USB-принтеров и выберите Настроить принтер, чтобы выбрать режим работы. Выберите режим Сетевой принтер, если используется только функция печати. Выберите Сетевое МФУ*, если требуется использовать функции печати, сканирования или факса.
  4. В Synology Assistant перейдите на вкладку Устройство принтера. Нажмите Добавить и следуйте инструкциям мастера установки для добавления принтера на компьютер. Если вы добавляете принтер впервые, подготовьте драйвер принтера для установки.

Подключение/отключение принтера:

При печати и отправке факса можно выполнять эти операции без ручного подключения принтера в Synology Assistant. Однако для использования функции сканера или получения факса на многофункциональном принтере необходимо подключить принтер вручную, чтобы избежать прерывания заданий печати другими пользователями.

Когда принтер подключен вручную в Synology Assistant, другие пользователи, использующие этот принтер в локальной сети, не смогут получить к нему доступ. Не забудьте отключить принтер после завершения печати.

Следуйте этим инструкциям для подключения или отключения принтера.

  1. В Synology Assistant перейдите на вкладку Устройство принтера.
  2. Выберите принтер, который хотите подключить, и нажмите Подключить. Synology Assistant начнет подключение к принтеру. В столбце статуса отобразится состояние операции.
  3. Когда принтер подключен, кнопка Подключить изменится на Отключить. Нажмите её для отключения принтера.

Примечание:

  • Если в столбце статуса отображается Доступен, вы можете подключить принтер для личного использования.
  • Если статус Подключен, принтер уже подключен к вашему компьютеру.
  • Если принтер временно недоступен, нажатие Подключить добавит вас в очередь ожидания подключения.

Удаление принтера:

  1. Выберите принтер, который хотите удалить из списка.
  2. Нажмите Удалить, чтобы удалить принтер из списка.

Редактирование информации о принтере:

Если Synology Assistant не может автоматически определить IP-адрес вашего принтера, вы можете вручную указать IP здесь.

  1. Выберите принтер, который хотите отредактировать.
  2. Нажмите Изменить и введите правильный IP-адрес принтера.

Примечание:

  • Сетевое МФУ доступно только для пользователей Windows.
  • Перед настройкой принтера ознакомьтесь со списком совместимых принтеров.
  • USB-концентраторы не поддерживаются при подключении принтера для общего доступа.
  • Функция работы с картой памяти подключенного принтера не поддерживается.

Настройки

Вы можете нажать на значок шестерёнки с подписью Настройки в правом верхнем углу для конфигурирования следующих параметров.

  • Вкладка функций по умолчанию: выберите вкладки функций, которые будут отображаться в Synology Assistant.
  • Язык: выберите язык интерфейса Synology Assistant по умолчанию. Для применения нового языка потребуется перезапустить Synology Assistant.
  • Тест памяти: если вы установите этот флажок, кнопка Тест памяти появится на вкладке Управление при следующем запуске Synology Assistant. Вы можете выбрать сервер и нажать эту кнопку для выполнения диагностики памяти. Сервер будет перезагружен, и тест начнётся. Ход тестирования будет отображаться в столбце Статус списка серверов.

Примечание:

  • Выполнение теста памяти может занять некоторое время в зависимости от объёма оперативной памяти сервера. На моделях с двумя контроллерами тестируйте только один контроллер за раз, чтобы система могла продолжать предоставлять сервисы во время теста.
  • Для устранения проблем с подключением к серверу через Synology Assistant воспользуйтесь этой статьёй.

Synology Assistant

Synology Assistant est un outil facile à utiliser pour gérer les systèmes de stockage sur le réseau local (LAN), en particulier lorsque vous avez plusieurs appareils fonctionnant au sein du LAN.

Pour télécharger et installer Synology Assistant sur votre ordinateur, rendez-vous sur le Centre de téléchargement et sélectionnez votre modèle. Ensuite, allez dans l'onglet Utilitaires du bureau pour trouver Synology Assistant.

Contrôle de base

Synology Assistant s'exécute en arrière-plan lorsqu'il est réduit dans la zone de notification système. Faites un clic droit sur l'icône pour accéder aux options suivantes :

  • Attacher/Libérer des imprimantes : jusqu'à 2 imprimantes
  • Ouvrir/Fermer Assistant

Gestion

Pour rechercher des systèmes de stockage sur le réseau local (LAN) :

Cliquez sur Rechercher pour actualiser la liste des systèmes de stockage présents sur votre LAN.

Pour se connecter à un serveur :

Vous pouvez vous connecter à votre serveur de l'une des manières suivantes :

  • Sélectionnez un serveur et cliquez sur Connecter.
  • Double-cliquez sur un serveur.

Pour mapper un lecteur :

Cliquez sur Mapper le lecteur pour mapper un dossier partagé en tant que lecteur réseau pour un accès local.

Pour configurer WOL :

Vous pouvez configurer Wake on LAN (WOL) pour réveiller à distance vos systèmes de stockage Synology si vous avez activé cette fonctionnalité dans Panneau de configuration > Matériel et alimentation > Général. Sélectionnez un serveur dans la liste et cliquez sur Configurer WOL. Pour plus d'informations, reportez-vous à la section WOL.

Remarque :

Les options de mappage de lecteur et de WOL ne sont pas disponibles si votre appareil Synology ne prend pas en charge ces fonctionnalités.

Statut

Ce tableau répertorie les statuts des appareils dans Synology Assistant et explique la signification de chaque statut.

Statut Indication du statut
Démarrage Le système est en cours de démarrage.
Vérification en cours Le système est en cours d'installation ou de configuration. Cliquez pour vérifier la progression.
Vérification du quota Le système vérifie le quota du disque. Cela peut être dû à un arrêt incorrect.
Vérification du système de fichiers (X minutes restantes) Le système vérifie le système de fichiers. Le processus sera terminé dans le nombre de minutes affiché. Cela se produit généralement lorsque le système détecte des erreurs de système de fichiers et vous invite à effectuer une vérification du système de fichiers.
Erreur de configuration Une erreur s'est produite lors de la configuration. Double-cliquez sur le serveur pour réappliquer les paramètres.
Configuration perdue Cela se produit généralement après un réinitialisation Mode 2, qui consiste à maintenir le bouton RESET enfoncé sur l'appareil. Vous pouvez double-cliquer sur le serveur et réinstaller le système d'exploitation (OS) pour repartir à zéro sans affecter les données du volume. Si vous n'avez pas appuyé sur le bouton RESET, consultez d'autres causes possibles pour ce message d'erreur.
Échec de la connexion Erreur de configuration réseau. Double-cliquez sur le serveur ou cliquez sur Configurer pour paramétrer les réglages réseau.
Vérification de l'état de la connexion Le système vérifie l'état de la connexion.
Migrable Les configurations système sur les disques peuvent être migrées vers cet appareil. Cela indique généralement que la version de l'OS enregistrée sur la carte mère est plus récente que celle sur les disques. Cela peut se produire après un service RMA. Double-cliquez sur le serveur pour terminer le processus de migration.
N/A WOL est configuré mais l'état actuel est inconnu. Reportez-vous à la section WOL pour plus d'informations.
Non configuré Les configurations initiales de l'OS (par exemple, le mot de passe admin) après l'installation n'ont pas été terminées. Double-cliquez sur le serveur pour finaliser la configuration.
Non installé Causes possibles : aucun disque n'est détecté sur votre serveur ; l'OS n'a pas été installé ; l'OS n'a pas été détecté sur les disques ; ou vous avez cliqué sur Effacer toutes les données dans Panneau de configuration > Mise à jour et restauration > Réinitialisation du système.
Solution : Assurez-vous que les disques sont sains, correctement insérés et détectés par le serveur. Ensuite, double-cliquez sur le serveur pour commencer l'installation de l'OS. Si l'OS était déjà installé sur les disques et que vous les utilisiez depuis un certain temps, ce message indique que le serveur ne peut pas reconnaître les données de l'OS sur les disques. Dans ce cas, annulez l'installation, éteignez le serveur, découvrez pourquoi les disques ne sont pas reconnus et effectuez des tests de diagnostic sur un ordinateur pour vérifier l'état de santé des disques.
Hors ligne Le système est hors ligne.
Test de mémoire en cours (X%) La progression du test de mémoire est à X %. Si l'on vous demande d'effectuer un test de mémoire, exécutez-le au moins 3 fois. Les résultats du test seront enregistrés dans le journal système. Veuillez générer un journal debug.dat et l'ajouter au ticket de support pour que Synology puisse enquêter.
Prêt Le système est installé et prêt à l'emploi. Double-cliquez sur le serveur ou cliquez sur Connecter pour accéder au serveur.
Récupérable Le système est récupérable. Cela indique généralement que la version de l'OS enregistrée sur la carte mère est plus ancienne que celle sur les disques. Cela peut se produire après un service RMA. Double-cliquez sur le serveur pour terminer le processus de récupération.
Démarrage des services Le système démarre les services. Cela peut prendre jusqu'à 10 minutes pour que tous les services soient complètement opérationnels.
Mise à niveau L'appareil met à jour l'OS. Veuillez patienter jusqu'à la fin du processus de mise à jour.

WOL

Pour configurer WOL :

  1. Allez dans Panneau de configuration > Matériel et alimentation > Général et activez WOL.
  2. Dans Synology Assistant, allez dans l'onglet Gestion. Sélectionnez un Synology NAS et cliquez sur Configurer WOL pour afficher l'adresse MAC disponible pour WOL.
  3. Après la configuration, le statut WOL du serveur dans l'onglet Gestion passera à « WOL ».

Remarque :

  1. La fonction WOL n'est prise en charge que sur certains modèles de Synology NAS. Reportez-vous au manuel du produit de votre serveur pour plus d'informations.
  2. Vous pouvez également faire un clic droit sur un serveur et sélectionner WOL > Configurer.

Pour réveiller un serveur :

  1. Faites un clic droit sur un serveur et cliquez sur WOL > Réveiller.
  2. Le statut WOL du serveur passera à « Progression X% », indiquant l'avancement du réveil.
  3. Lorsque WOL est terminé, le statut WOL passera à « WOL ». Pour plus d'informations sur les statuts WOL, reportez-vous au tableau suivant.
    4. Statut WOL Indication du statut
    WOL
    1. WOL est configuré.
    2. Le serveur est allumé.
    --
    1. WOL n'est pas configuré.
    2. Le serveur ne prend pas en charge la fonction WOL.
    Progression X% Le serveur est en cours d'allumage. La progression du réveil est à X %.
    Éteint Le serveur est éteint.
    N/A WOL est configuré mais l'état actuel est inconnu.

Pour désactiver WOL pour un serveur :

  1. Faites un clic droit sur un serveur et cliquez sur WOL > Supprimer.
  2. Le statut WOL du serveur passera à « -- ».

Périphérique d'impression

Dans Synology Assistant, vous pouvez gérer de façon centralisée les imprimantes connectées à votre Synology NAS dans l'onglet Périphérique d'impression. Les imprimantes simples et multifonctions sont prises en charge. Pour partager une imprimante connectée au Synology NAS sur le LAN via Synology Assistant, suivez ces instructions.

Notez que les périphériques d'impression ne sont pris en charge que sur certains modèles de Synology NAS fonctionnant sous DSM. Reportez-vous au manuel du produit de votre serveur pour plus d'informations.

Pour ajouter une imprimante :

  1. Connectez l'imprimante à votre Synology NAS.
  2. Configurez le mode d'impression dans Panneau de configuration > Périphériques externes. Une liste des imprimantes connectées s'affichera ici.
  3. Sélectionnez l'imprimante, cliquez sur Gestionnaire d'imprimante USB et choisissez Configurer l'imprimante pour sélectionner le mode de fonctionnement de votre imprimante. Choisissez le mode Imprimante réseau si vous utilisez uniquement la fonction d'impression. Choisissez Multifonctions réseau* si vous souhaitez utiliser les fonctions d'impression, de numérisation ou de télécopie.
  4. Dans Synology Assistant, allez dans l'onglet Périphérique d'impression. Cliquez sur Ajouter et suivez l'assistant de configuration pour ajouter l'imprimante à votre ordinateur. Si c'est la première fois que vous ajoutez l'imprimante, préparez le pilote d'impression pour l'installation.

Pour attacher/libérer une imprimante :

Pour imprimer ou envoyer une télécopie, vous pouvez effectuer ces opérations sans attacher manuellement l'imprimante dans Synology Assistant. Cependant, si vous souhaitez utiliser la fonction de numérisation ou recevoir une télécopie sur une imprimante multifonction, vous devez attacher l'imprimante pour éviter que les travaux d'impression ne soient interrompus par d'autres utilisateurs.

Lorsqu'une imprimante est attachée manuellement dans Synology Assistant, les autres utilisateurs partageant la même imprimante sur le LAN ne peuvent pas accéder à l'appareil. Pensez à libérer l'imprimante lorsque vous avez terminé votre tâche d'impression.

Vous pouvez suivre ces instructions pour attacher ou libérer l'imprimante.

  1. Dans Synology Assistant, allez dans l'onglet Périphérique d'impression.
  2. Sélectionnez l'imprimante que vous souhaitez attacher et cliquez sur Attacher. Synology Assistant commencera à connecter l'imprimante. La colonne de statut affichera l'état de l'opération.
  3. Lorsqu'une imprimante est attachée, le bouton Attacher devient Libérer. Vous pouvez cliquer dessus pour libérer l'imprimante attachée.

Remarque :

  • Dans la colonne de statut, si le statut de l'imprimante est Disponible, vous pouvez attacher l'imprimante pour votre usage exclusif.
  • Si le statut est Attachée, l'imprimante est déjà attachée à votre ordinateur.
  • Si l'imprimante n'est pas disponible pour le moment, cliquer sur Attacher vous ajoutera à la liste d'attente pour la connexion.

Pour supprimer une imprimante :

  1. Sélectionnez l'imprimante que vous souhaitez supprimer de la liste.
  2. Cliquez sur Supprimer pour retirer l'imprimante de la liste.

Pour modifier les informations de l'imprimante :

Lorsque Synology Assistant ne parvient pas à détecter automatiquement l'IP de votre imprimante, vous pouvez la configurer manuellement ici.

  1. Sélectionnez l'imprimante que vous souhaitez modifier.
  2. Cliquez sur Modifier et saisissez l'IP correcte de votre imprimante.

Remarque :

  • Le mode Multifonctions réseau est réservé aux utilisateurs Windows.
  • Avant de configurer une imprimante, consultez la liste des imprimantes compatibles.
  • Les concentrateurs USB ne sont pas pris en charge lors du partage d'une imprimante.
  • La fonction carte mémoire de l'imprimante connectée n'est pas prise en charge.

Préférences

Vous pouvez cliquer sur l'icône d'engrenage intitulée Préférences en haut à droite pour configurer les paramètres suivants.

  • Onglet des fonctions par défaut : sélectionnez les onglets de fonction à afficher dans Synology Assistant.
  • Langue : choisissez une langue par défaut pour l'interface utilisateur de Synology Assistant. Vous devrez redémarrer Synology Assistant pour que le nouveau paramètre prenne effet.
  • Test de mémoire : si vous cochez la case, le bouton Test de mémoire apparaîtra dans l'onglet Gestion lors du prochain lancement de Synology Assistant. Vous pouvez sélectionner un serveur et cliquer sur le bouton pour effectuer un test de diagnostic mémoire. Le serveur sera redémarré et le test commencera. La progression du test sera affichée dans la colonne Statut de la liste des serveurs.

Remarque :

  • Le test de mémoire peut prendre un certain temps, selon la taille de la mémoire physique de votre serveur. Sur les modèles à double contrôleur, testez un seul contrôleur à la fois afin que le système puisse continuer à fournir des services pendant le test.
  • Résolvez les problèmes de connexion à votre serveur via Synology Assistant avec cet article.

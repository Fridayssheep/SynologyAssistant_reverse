Synology Assistant

O Synology Assistant é uma ferramenta fácil de utilizar para gerir sistemas de armazenamento na rede local (LAN), especialmente quando tem vários dispositivos a funcionar dentro da LAN.

Para transferir e instalar o Synology Assistant no seu computador, aceda ao Centro de transferências e selecione o seu modelo. Em seguida, vá ao separador Utilitários de ambiente de trabalho para encontrar o Synology Assistant.

Controlo Básico

O Synology Assistant é executado em segundo plano quando minimizado para a área de notificação do sistema. Clique com o botão direito do rato no ícone para aceder às seguintes opções:

  • Ligar/Desligar impressoras: Até 2 impressoras
  • Abrir/Fechar o Assistant

Gestão

Para procurar sistemas de armazenamento na LAN:

Clique em Procurar para atualizar a lista de sistemas de armazenamento na sua LAN.

Para ligar a um servidor:

Pode ligar-se ao seu servidor de uma das seguintes formas:

  • Selecione um servidor e clique em Ligar.
  • Clique duas vezes num servidor.

Para mapear uma unidade:

Clique em Mapear unidade para mapear uma pasta partilhada como unidade de rede para acesso local.

Para configurar o WOL:

Pode configurar o Wake on LAN (WOL) para ligar remotamente os seus sistemas de armazenamento Synology se tiver ativado esta funcionalidade em Painel de Controlo > Hardware e Energia > Geral. Selecione um servidor da lista e clique em Configurar WOL. Para mais informações, consulte a secção WOL.

Nota:

As opções de mapeamento de unidade e WOL não estão disponíveis se o seu dispositivo Synology não suportar estas funcionalidades.

Esta tabela lista os estados dos dispositivos no Synology Assistant e explica o significado de cada estado.

Verificar progresso O sistema está a ser instalado ou configurado. Clique para verificar o progresso.
A verificar a quota O sistema está a verificar a quota da unidade. Isto pode ser resultado de um encerramento incorreto.
A verificar o sistema de ficheiros (X minutos restantes) O sistema está a verificar o sistema de ficheiros. O processo será concluído no número de minutos apresentado. Isto normalmente ocorre quando o sistema deteta erros no sistema de ficheiros e solicita que execute uma verificação do sistema de ficheiros.
Erro de configuração Ocorreu um erro durante a configuração. Clique duas vezes no servidor para reaplicar as definições.
Configuração perdida Isto normalmente ocorre após um Reinício de Modo 2, que consiste em pressionar e manter pressionado o botão RESET no dispositivo. Pode clicar duas vezes no servidor e reinstalar o sistema operativo (SO) para começar de novo sem afetar os dados no volume. Se não pressionou o botão RESET, consulte outras possíveis causas para esta mensagem de erro.
Falha na ligação Erro de configuração de rede. Clique duas vezes no servidor ou clique em Configurar para configurar as definições de rede.
A obter estado da ligação O sistema está a verificar o estado da ligação.
Migrável As configurações do sistema nos discos podem ser migradas para este dispositivo. Isto normalmente indica que a versão do SO registada na motherboard é mais recente do que a versão nos discos. É provável que ocorra após um serviço RMA. Clique duas vezes no servidor para concluir o processo de migração.
N/D O WOL está configurado, mas o estado atual é desconhecido. Consulte a secção WOL para mais informações.
Não configurado As configurações iniciais do SO (por exemplo, palavra-passe do admin) após a instalação não foram concluídas. Clique duas vezes no servidor para terminar a configuração.
Não instalado Possíveis causas: não foram detetados discos no seu servidor; o SO não foi instalado; o SO não foi detetado nos discos; ou clicou em Apagar Todos os Dados em Painel de Controlo > Atualizar & Restaurar > Reiniciar Sistema.
Solução: Certifique-se de que os discos estão saudáveis, inseridos corretamente e podem ser detetados pelo servidor. Depois, clique duas vezes no servidor para iniciar a instalação do SO. Se o SO já estava instalado nos discos e já utilizava os discos há algum tempo, esta mensagem indica que o servidor não consegue reconhecer os dados do SO nos discos. Neste caso, aborte a instalação, desligue o servidor, saiba porque os discos não são reconhecidos e execute testes de diagnóstico num computador para verificar o estado dos discos.
Offline O sistema está offline.
A executar Teste de Memória (X%) O progresso do teste de memória está em X%. Se lhe for pedido para executar um teste de memória, execute-o pelo menos 3 vezes. Os resultados do teste serão guardados no registo do sistema. Por favor, gere um registo debug.dat e anexe-o ao pedido de suporte para a Synology investigar.
Pronto O sistema está instalado e pronto a utilizar. Clique duas vezes no servidor ou clique em Ligar para aceder ao servidor.
Recuperável O sistema é recuperável. Isto normalmente indica que a versão do SO registada na motherboard é mais antiga do que a versão nos discos. Isto é provável de ocorrer após um serviço RMA. Clique duas vezes no servidor para concluir o processo de recuperação.
A iniciar serviços O sistema está a iniciar os serviços. Pode demorar até 10 minutos para que todos os serviços estejam totalmente operacionais.
A atualizar O dispositivo está a atualizar o SO. Aguarde que o processo de atualização termine.

WOL

Para configurar o WOL:

  1. Aceda a Painel de Controlo > Hardware e Energia > Geral e ative o WOL.
  2. No Synology Assistant, vá ao separador Gestão. Selecione um Synology NAS e clique em Configurar WOL para ver o endereço MAC disponível para WOL.
  3. Após a configuração, o estado do WOL do servidor no separador Gestão mudará para "WOL".

Nota:

  1. A funcionalidade WOL é suportada apenas em alguns modelos Synology NAS. Consulte o manual do produto do seu servidor para mais informações.
  2. Também pode clicar com o botão direito do rato num servidor e selecionar WOL > Configurar.

Para ligar um servidor:

  1. Clique com o botão direito do rato num servidor e clique em WOL > Ligar.
  2. O Estado do WOL do servidor mudará para "Progresso X%", indicando o progresso do arranque.
  3. Quando o WOL estiver concluído, o estado do WOL mudará para "WOL". Para mais informações sobre os estados do WOL, consulte a tabela seguinte.
    4. Estado WOL Indicação do Estado
    WOL
    1. O WOL está configurado.
    2. O servidor está ligado.
    --
    1. O WOL não está configurado.
    2. O servidor não suporta a funcionalidade WOL.
    Progresso X% O servidor está a ligar. O progresso do arranque é X%.
    Desligado O servidor está desligado.
    N/D O WOL está configurado mas o estado atual é desconhecido.

Para desativar o WOL num servidor:

  1. Clique com o botão direito do rato num servidor e clique em WOL > Remover.
  2. O estado do WOL do servidor mudará para "--".

Dispositivo de Impressora

No Synology Assistant, pode gerir centralmente as impressoras ligadas ao seu Synology NAS no separador Dispositivo de Impressora. São suportadas impressoras básicas e multifunções. Para partilhar uma impressora ligada ao Synology NAS na LAN através do Synology Assistant, siga estas instruções.

Note que os dispositivos de impressora são suportados apenas em alguns modelos Synology NAS com DSM. Consulte o manual do produto do seu servidor para mais informações.

Para adicionar uma impressora:

  1. Ligue a impressora ao seu Synology NAS.
  2. Configure o modo da impressora em Painel de Controlo > Dispositivos Externos. Aqui é apresentada uma lista das impressoras ligadas.
  3. Selecione a impressora, clique em Gestor de Impressoras USB e escolha Configurar Impressora para selecionar o modo de funcionamento da sua impressora. Escolha o modo Impressora de Rede se utilizar apenas a função de impressão. Escolha Network MFP* se pretender utilizar as funções de impressão, digitalização ou fax.
  4. No Synology Assistant, vá ao separador Dispositivo de Impressora. Clique em Adicionar e siga o Assistente de Configuração para adicionar a impressora ao seu computador. Se for a primeira vez que adiciona a impressora, tenha o driver da impressora pronto para instalação.

Para ligar/desligar uma impressora:

Ao imprimir e enviar fax, pode realizar as operações sem ligar manualmente a impressora no Synology Assistant. No entanto, se pretender utilizar a função de digitalização ou receber fax numa impressora multifunções, tem de ligar a impressora para evitar que os trabalhos de impressão sejam interrompidos por outros utilizadores.

Quando uma impressora está ligada manualmente no Synology Assistant, outros utilizadores que partilham a mesma impressora na LAN não podem aceder ao dispositivo. Certifique-se de que desliga a impressora quando terminar o seu trabalho de impressão.

Pode seguir estas instruções para ligar ou desligar a impressora.

  1. No Synology Assistant, vá ao separador Dispositivo de Impressora.
  2. Selecione a impressora que pretende ligar e clique em Ligar. O Synology Assistant irá iniciar a ligação à impressora. A coluna de estado irá mostrar o estado da operação.
  3. Quando uma impressora está ligada, o botão Ligar passa a Desligar. Pode clicar para desligar a impressora ligada.

Nota:

  • Na coluna de estado, se o estado da impressora for Disponível, pode ligar a impressora para uso exclusivo.
  • Se o estado for Ligada, a impressora já está ligada ao seu computador.
  • Se a impressora não estiver disponível de momento, clicar em Ligar irá adicioná-lo à lista de espera para ligação.

Para remover uma impressora:

  1. Selecione a impressora que pretende remover da lista.
  2. Clique em Remover para eliminar a impressora da lista.

Para editar informações da impressora:

Quando o Synology Assistant não consegue detetar automaticamente o IP da sua impressora, pode configurar manualmente o IP aqui.

  1. Selecione a impressora que pretende editar.
  2. Clique em Editar e introduza o IP correto da sua impressora.

Nota:

  • Network MFP é apenas para utilizadores Windows.
  • Antes de configurar uma impressora, consulte a lista de impressoras compatíveis.
  • Não é suportado o uso de hub USB ao ligar uma impressora para partilha.
  • A função de cartão de memória da impressora ligada não é suportada.

Preferências

Pode clicar no ícone de engrenagem identificado como Preferências no canto superior direito para configurar as seguintes definições.

  • Separador de Funções Padrão: Selecione os separadores de funções a apresentar no Synology Assistant.
  • Idioma: Escolha um idioma padrão para a interface do utilizador do Synology Assistant. Terá de reiniciar o Synology Assistant para que a nova definição tenha efeito.
  • Teste de Memória: Se selecionar a caixa de verificação, o botão Teste de Memória aparecerá no separador Gestão da próxima vez que iniciar o Synology Assistant. Pode selecionar um servidor e clicar no botão para realizar um teste de diagnóstico de memória. O servidor será reiniciado e o teste terá início. O progresso do teste será apresentado na coluna Estado da lista de servidores.

Nota:

  • Pode demorar algum tempo a concluir o teste de memória, dependendo do tamanho da memória física do seu servidor. Em modelos com dois controladores, teste apenas um controlador de cada vez para que o sistema possa continuar a fornecer serviços durante o teste.
  • Resolva problemas de ligação ao seu servidor através do Synology Assistant com este artigo.

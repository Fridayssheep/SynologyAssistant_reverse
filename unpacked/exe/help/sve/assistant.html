Synology Assistant

Synology Assistant är ett lättanvänt verktyg för att hantera lagringssystem i det lokala nätverket (LAN), särskilt när du har flera enheter som arbetar inom samma LAN.

För att ladda ner och installera Synology Assistant på din dator, gå till Nedladdningscenter och välj din modell. Gå sedan till fliken Skrivbordsverktyg för att hitta Synology Assistant.

Grundläggande kontroll

Synology Assistant körs i bakgrunden när den minimeras till systemfältet. Högerklicka på ikonen för följande alternativ:

  • Anslut/frigör skrivare: Upp till 2 skrivare
  • Öppna/stäng Assistant

Hantering

Så här söker du lagringssystem i LAN:

Klicka på Sök för att uppdatera listan över lagringssystem i ditt LAN.

Så här ansluter du till en server:

Du kan ansluta till din server på något av följande sätt:

  • Välj en server och klicka på Anslut.
  • Dubbelklicka på en server.

Så här mappar du en enhet:

Klicka på Mappa enhet för att mappa en delad mapp som en nätverksenhet för lokal åtkomst.

Så här ställer du in WOL:

Du kan ställa in Wake on LAN (WOL) för att väcka dina Synology-lagringssystem på distans om du har aktiverat denna funktion i Kontrollpanel > Maskinvara & Ström > Allmänt. Välj en server från listan och klicka på Ställ in WOL. För mer information, se avsnittet WOL.

Obs:

Alternativen för enhetsmappning och WOL är inte tillgängliga om din Synology-enhet inte stöder funktionerna.

WOL

Så här ställer du in WOL:

  1. Gå till Kontrollpanel > Maskinvara & Ström > Allmänt och aktivera WOL.
  2. I Synology Assistant, gå till fliken Hantering. Välj en Synology NAS och klicka på Ställ in WOL för att visa MAC-adressen som är tillgänglig för WOL.
  3. Efter installationen kommer serverns WOL-status på fliken Hantering att ändras till "WOL".

Obs:

  1. WOL-funktionen stöds endast på vissa Synology NAS-modeller. Se din servers produktmanual för mer information.
  2. Du kan också högerklicka på en server och välja WOL > Ställ in.

Så här väcker du en server:

  1. Högerklicka på en server och klicka på WOL > Väck.
  2. Serverns WOL-status ändras till "Förlopp X%", vilket visar väckningsförloppet.
  3. När WOL är klart ändras WOL-statusen till "WOL". För mer information om WOL-statusar, se följande tabell.

    --

Så här inaktiverar du WOL för en server:

  1. Högerklicka på en server och klicka på WOL > Ta bort.
  2. WOL-statusen för servern ändras till "--".

Skrivarhantering

I Synology Assistant kan du centralt hantera skrivare som är anslutna till din Synology NAS på fliken Skrivarhantering. Både enkla och multifunktionella skrivare stöds. För att dela en skrivare ansluten till Synology NAS i LAN via Synology Assistant, följ dessa instruktioner.

Observera att skrivarenheter endast stöds på vissa Synology NAS-modeller som kör DSM. Se din servers produktmanual för mer information.

Så här lägger du till en skrivare:

  1. Anslut skrivaren till din Synology NAS.
  2. Ställ in skrivarläge i Kontrollpanel > Externa enheter. En lista över anslutna skrivare visas här.
  3. Välj skrivaren, klicka på USB Printer Manager och välj Installera skrivare för att välja driftläge för din skrivare. Välj Nätverksskrivare om du endast använder utskriftsfunktionen. Välj Network MFP* om du vill använda utskrift, skanning eller fax.
  4. I Synology Assistant, gå till fliken Skrivarhantering. Klicka på Lägg till och följ installationsguiden för att lägga till skrivaren på din dator. Om detta är första gången du lägger till skrivaren, ha din skrivardrivrutin redo för installation.

Så här ansluter/frigör du en skrivare:

När du skriver ut eller skickar fax kan du utföra dessa åtgärder utan att manuellt ansluta skrivaren i Synology Assistant. Men om du vill använda skannerfunktionen eller ta emot fax på en multifunktionsskrivare måste du ansluta skrivaren för att förhindra att utskriftsjobb avbryts av andra användare.

När en skrivare är manuellt ansluten i Synology Assistant kan andra användare som delar samma skrivare i LAN inte komma åt enheten. Se till att frigöra skrivaren när du är klar med ditt utskriftsjobb.

Du kan följa dessa instruktioner för att ansluta eller frigöra skrivaren.

  1. I Synology Assistant, gå till fliken Skrivarhantering.
  2. Välj skrivaren du vill ansluta och klicka på Anslut. Synology Assistant börjar då ansluta skrivaren. Statuskolumnen visar åtgärdsstatusen.
  3. När en skrivare är ansluten blir knappen Anslut till Frigör. Du kan klicka på den för att frigöra den anslutna skrivaren.

Obs:

  • I statuskolumnen, om skrivaren har statusen Tillgänglig, kan du ansluta skrivaren för eget bruk.
  • Om statusen är Ansluten är skrivaren redan ansluten till din dator.
  • Om skrivaren inte är tillgänglig för tillfället, kommer ett klick på Anslut att lägga dig i väntelistan för anslutning.

Så här tar du bort en skrivare:

  1. Välj skrivaren du vill ta bort från listan.
  2. Klicka på Ta bort för att radera skrivaren från listan.

Så här redigerar du skrivarens information:

När Synology Assistant inte automatiskt kan hitta IP-adressen till din skrivare kan du manuellt ange IP-adressen här.

  1. Välj skrivaren du vill redigera.
  2. Klicka på Redigera och ange rätt IP-adress för din skrivare.

Obs:

  • Network MFP är endast för Windows-användare.
  • Innan du ställer in en skrivare, se listan över kompatibla skrivare.
  • USB-hubb stöds inte vid anslutning av skrivare för delning.
  • Funktionen för minneskort på den anslutna skrivaren stöds inte.

Inställningar

Du kan klicka på kugghjulsikonen märkt Inställningar uppe till höger för att konfigurera följande inställningar.

  • Standardflikar: Välj vilka funktionsflikar som ska visas i Synology Assistant.
  • Språk: Välj standardspråk för Synology Assistants användargränssnitt. Du måste starta om Synology Assistant för att den nya inställningen ska börja gälla.
  • Minnestest: Om du markerar kryssrutan visas knappen Minnestest på fliken Hantering nästa gång du startar Synology Assistant. Du kan välja en server och klicka på knappen för att utföra ett minnesdiagnostiskt test. Servern kommer att startas om och testet påbörjas. Testets förlopp visas i kolumnen Status i serverlistan.

Obs:

  • Det kan ta en stund att slutföra minnestestet, beroende på mängden fysiskt minne i din server. På modeller med dubbla kontroller bör du bara testa en kontroll i taget så att systemet fortfarande kan tillhandahålla tjänster under testet.
  • Felsök anslutningsproblem till din server via Synology Assistant med denna artikel.

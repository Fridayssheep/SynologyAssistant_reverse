Synology Assistant

Synology Assistant는 로컬 네트워크(LAN)에서 스토리지 시스템을 관리하기 위한 사용이 간편한 도구로, 특히 여러 대의 장치가 LAN 내에서 작동할 때 유용합니다.

컴퓨터에 Synology Assistant를 다운로드하여 설치하려면 다운로드 센터로 이동하여 모델을 선택하세요. 다음으로 데스크톱 유틸리티 탭에서 Synology Assistant를 찾을 수 있습니다.

기본 제어

Synology Assistant는 최소화 시 시스템 트레이에서 백그라운드로 실행됩니다. 아이콘을 마우스 오른쪽 버튼으로 클릭하면 다음 옵션을 사용할 수 있습니다:

  • 프린터 연결/해제: 최대 2대의 프린터
  • Assistant 열기/닫기

관리

LAN에서 스토리지 시스템을 검색하려면:

LAN 내 스토리지 시스템 목록을 새로 고치려면 검색을 클릭하세요.

서버에 연결하려면:

다음 두 가지 방법 중 하나로 서버에 연결할 수 있습니다:

  • 서버를 선택하고 연결을 클릭합니다.
  • 서버를 더블 클릭합니다.

드라이브를 매핑하려면:

공유 폴더를 로컬에서 액세스할 수 있는 네트워크 드라이브로 매핑하려면 드라이브 매핑을 클릭하세요.

WOL을 설정하려면:

제어판 > 하드웨어 및 전원 > 일반에서 이 기능을 활성화한 경우, Synology 스토리지 시스템을 원격으로 깨우기 위해 Wake on LAN(WOL)을 설정할 수 있습니다. 목록에서 서버를 선택하고 WOL 설정을 클릭하세요. 자세한 내용은 WOL 섹션을 참조하세요.

참고:

Synology 장치가 해당 기능을 지원하지 않는 경우 드라이브 매핑 및 WOL 옵션을 사용할 수 없습니다.

상태

이 표는 Synology Assistant에서 장치 상태를 나열하고 각 상태가 의미하는 바를 설명합니다.

상태 상태 설명
부팅 중 시스템이 부팅 중입니다.
진행 상황 확인 시스템이 설치 또는 구성 중입니다. 클릭하여 진행 상황을 확인하세요.
할당량 확인 중 시스템이 드라이브 할당량을 확인 중입니다. 이는 잘못된 종료로 인해 발생할 수 있습니다.
파일 시스템 확인 중(X분 남음) 시스템이 파일 시스템을 확인 중입니다. 이 과정은 표시된 분 내에 완료됩니다. 일반적으로 시스템이 파일 시스템 오류를 감지하고 파일 시스템 검사를 수행하라는 메시지가 표시될 때 발생합니다.
구성 오류 구성 중 오류가 발생했습니다. 서버를 더블 클릭하여 설정을 다시 적용하세요.
구성 손실 이 현상은 일반적으로 장치의 RESET 버튼을 길게 눌러 수행하는 모드 2 리셋 후에 발생합니다. 서버를 더블 클릭하여 운영 체제(OS)를 다시 설치하면 볼륨 내 데이터에 영향을 주지 않고 새로 시작할 수 있습니다. RESET 버튼을 누르지 않았다면, 이 오류 메시지의 다른 가능한 원인을 확인하세요.
연결 실패 네트워크 구성 오류입니다. 서버를 더블 클릭하거나 설정을 클릭하여 네트워크 설정을 구성하세요.
연결 상태 확인 중 시스템이 연결 상태를 확인 중입니다.
마이그레이션 가능 드라이브의 시스템 구성을 이 장치로 마이그레이션할 수 있습니다. 이는 일반적으로 메인보드에 기록된 OS 버전이 드라이브의 OS 버전보다 최신일 때 발생합니다. RMA 서비스 이후에 발생할 수 있습니다. 서버를 더블 클릭하여 마이그레이션을 완료하세요.
N/A WOL이 설정되어 있지만 현재 상태는 알 수 없습니다. 자세한 내용은 WOL 섹션을 참조하세요.
미구성 설치 후 초기 OS 구성(예: admin 비밀번호)이 완료되지 않았습니다. 서버를 더블 클릭하여 구성을 마치세요.
미설치 가능한 원인: 서버에서 드라이브가 감지되지 않음, OS가 설치되지 않음, 드라이브에서 OS가 감지되지 않음, 또는 제어판 > 업데이트 및 복원 > 시스템 재설정에서 모든 데이터 지우기를 클릭함.
해결 방법: 드라이브가 정상이고 올바르게 삽입되어 서버에서 감지되는지 확인하세요. 그런 다음 서버를 더블 클릭하여 OS 설치를 시작하세요. 이미 드라이브에 OS가 설치되어 있고 한동안 사용 중이었다면, 이 메시지는 서버가 드라이브의 OS 데이터를 인식하지 못함을 의미합니다. 이 경우 설치를 중단하고 서버를 종료한 후, 드라이브가 인식되지 않는 이유 알아보기 및 진단 테스트 실행을 통해 드라이브의 상태를 컴퓨터에서 확인하세요.
오프라인 시스템이 오프라인 상태입니다.
메모리 테스트 수행 중(X%) 메모리 테스트 진행률이 X%입니다. 메모리 테스트를 요청받은 경우 최소 3회 실행하세요. 테스트 결과는 시스템 로그에 저장됩니다. Synology에서 조사할 수 있도록 debug.dat 로그 생성 후 지원 티켓에 첨부하세요.
준비 완료 시스템이 설치되어 사용 준비가 완료되었습니다. 서버를 더블 클릭하거나 연결을 클릭하여 서버에 액세스하세요.
복구 가능 시스템을 복구할 수 있습니다. 이는 일반적으로 메인보드에 기록된 OS 버전이 드라이브의 OS 버전보다 오래된 경우 발생합니다. RMA 서비스 이후에 발생할 수 있습니다. 서버를 더블 클릭하여 복구를 완료하세요.
서비스 시작 중 시스템이 서비스를 시작 중입니다. 모든 서비스가 완전히 시작되기까지 최대 10분이 소요될 수 있습니다.
업그레이드 중 장치가 OS를 업데이트 중입니다. 업데이트가 완료될 때까지 기다려 주세요.

WOL

WOL을 설정하려면:

  1. 제어판 > 하드웨어 및 전원 > 일반으로 이동하여 WOL을 활성화하세요.
  2. Synology Assistant에서 관리 탭으로 이동합니다. Synology NAS를 선택하고 WOL 설정을 클릭하면 WOL에 사용할 수 있는 MAC 주소를 확인할 수 있습니다.
  3. 설정이 완료되면 관리 탭의 서버 WOL 상태가 "WOL"로 변경됩니다.

참고:

  1. WOL 기능은 일부 Synology NAS 모델에서만 지원됩니다. 자세한 내용은 서버의 제품 설명서를 참조하세요.
  2. 서버를 마우스 오른쪽 버튼으로 클릭한 후 WOL > 설정을 선택할 수도 있습니다.

서버를 깨우려면:

  1. 서버를 마우스 오른쪽 버튼으로 클릭하고 WOL > 깨우기를 클릭하세요.
  2. 서버의 WOL 상태가 "진행률 X%"로 변경되어 깨우기 진행 상황을 나타냅니다.
  3. WOL이 완료되면 WOL 상태가 "WOL"로 변경됩니다. WOL 상태에 대한 자세한 내용은 아래 표를 참조하세요.
    4. WOL 상태 상태 설명
    WOL
    1. WOL이 설정되었습니다.
    2. 서버가 켜져 있습니다.
    --
    1. WOL이 설정되지 않았습니다.
    2. 서버가 WOL 기능을 지원하지 않습니다.
    진행률 X% 서버가 켜지는 중입니다. 깨우기 진행률은 X%입니다.
    꺼짐 서버가 꺼져 있습니다.
    N/A WOL이 설정되어 있지만 현재 상태는 알 수 없습니다.

서버에서 WOL을 비활성화하려면:

  1. 서버를 마우스 오른쪽 버튼으로 클릭하고 WOL > 제거를 클릭하세요.
  2. 서버의 WOL 상태가 "--"로 변경됩니다.

프린터 장치

Synology Assistant에서는 프린터 장치 탭에서 Synology NAS에 연결된 프린터를 중앙에서 관리할 수 있습니다. 기본 프린터와 복합기 모두 지원됩니다. Synology Assistant를 통해 LAN에서 Synology NAS에 연결된 프린터를 공유하려면 다음 지침을 따르세요.

프린터 장치는 DSM이 실행되는 일부 Synology NAS 모델에서만 지원됩니다. 자세한 내용은 서버의 제품 설명서를 참조하세요.

프린터를 추가하려면:

  1. 프린터를 Synology NAS에 연결하세요.
  2. 제어판 > 외부 장치에서 프린터 모드를 설정하세요. 연결된 프린터 목록이 여기에 표시됩니다.
  3. 프린터를 선택하고 USB 프린터 관리자를 클릭한 후 프린터 설정을 선택하여 프린터의 동작 모드를 선택하세요. 인쇄 기능만 사용할 경우 네트워크 프린터 모드를 선택하세요. 인쇄, 스캔 또는 팩스 기능을 사용하려면 네트워크 MFP*를 선택하세요.
  4. Synology Assistant에서 프린터 장치 탭으로 이동합니다. 추가를 클릭하고 설치 마법사의 안내에 따라 프린터를 컴퓨터에 추가하세요. 프린터를 처음 추가하는 경우 프린터 드라이버를 미리 준비하세요.

프린터 연결/해제 방법:

인쇄 및 팩스 전송 시에는 Synology Assistant에서 프린터를 수동으로 연결하지 않아도 작업을 수행할 수 있습니다. 그러나 복합기에서 스캐너 기능을 사용하거나 팩스를 수신하려면, 다른 사용자의 인쇄 작업이 방해받지 않도록 프린터를 연결해야 합니다.

Synology Assistant에서 프린터를 수동으로 연결하면, LAN에서 동일한 프린터를 공유하는 다른 사용자는 해당 장치에 접근할 수 없습니다. 인쇄 작업이 끝나면 반드시 프린터 연결을 해제하세요.

다음 지침에 따라 프린터를 연결하거나 해제할 수 있습니다.

  1. Synology Assistant에서 프린터 장치 탭으로 이동합니다.
  2. 연결할 프린터를 선택하고 연결을 클릭하세요. Synology Assistant가 프린터 연결을 시작합니다. 상태 열에 동작 상태가 표시됩니다.
  3. 프린터가 연결되면 연결 버튼이 해제로 바뀝니다. 클릭하여 연결된 프린터를 해제할 수 있습니다.

참고:

  • 상태 열에서 프린터 상태가 사용 가능이면, 프린터를 단독으로 연결할 수 있습니다.
  • 상태가 연결됨이면, 프린터가 이미 컴퓨터에 연결되어 있습니다.
  • 프린터를 당장 사용할 수 없는 경우 연결을 클릭하면 연결 대기 목록에 추가됩니다.

프린터를 제거하려면:

  1. 목록에서 제거할 프린터를 선택하세요.
  2. 제거를 클릭하여 프린터를 목록에서 삭제하세요.

프린터 정보를 편집하려면:

Synology Assistant가 프린터의 IP를 자동으로 감지하지 못할 경우, 여기에서 수동으로 IP를 설정할 수 있습니다.

  1. 편집할 프린터를 선택하세요.
  2. 편집을 클릭하고 프린터의 올바른 IP를 입력하세요.

참고:

  • 네트워크 MFP는 Windows 사용자만 사용할 수 있습니다.
  • 프린터를 설정하기 전에 호환 프린터 목록을 참조하세요.
  • 프린터 공유 시 USB 허브는 지원되지 않습니다.
  • 연결된 프린터의 메모리 카드 기능은 지원되지 않습니다.

환경설정

오른쪽 상단의 기어 아이콘 환경설정을 클릭하여 다음 설정을 구성할 수 있습니다.

  • 기본 기능 탭: Synology Assistant에 표시할 기능 탭을 선택합니다.
  • 언어: Synology Assistant 사용자 인터페이스의 기본 언어를 선택합니다. 새 설정을 적용하려면 Synology Assistant를 다시 시작해야 합니다.
  • 메모리 테스트: 체크박스를 선택하면 다음에 Synology Assistant를 실행할 때 관리 탭에 메모리 테스트 버튼이 표시됩니다. 서버를 선택하고 해당 버튼을 클릭하여 메모리 진단 테스트를 수행할 수 있습니다. 서버가 재부팅되며 테스트가 시작됩니다. 테스트 진행 상황은 서버 목록의 상태 열에 표시됩니다.

참고:

  • 메모리 테스트 완료까지는 서버의 실제 메모리 크기에 따라 시간이 걸릴 수 있습니다. 듀얼 컨트롤러 모델에서는 한 번에 하나의 컨트롤러만 테스트하여 테스트 중에도 시스템이 서비스를 제공할 수 있도록 하세요.
  • Synology Assistant를 통해 서버 연결 문제를 해결하려면 이 문서를 참조하세요.
